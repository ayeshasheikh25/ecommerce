# E-Commerce Grocery Web App (React)

This is a frontend-based e-commerce grocery web application built using React.js. The project simulates a real online shopping platform where users can browse products, view categories, and manage a shopping cart.

## Project Overview

This application includes a modern UI for an online grocery store with features like product browsing, category navigation, and cart functionality. It is designed as a practice project to improve React.js skills and frontend development concepts.

## Features

- Home page with product listings
- Category-based browsing (Food, Fruits, Vegetables, etc.)
- Product cards with name, price, and discount display
- Add to Cart functionality
- Responsive layout for different screen sizes

## Tech Stack

- React.js
- Tailwind CSS 
- React Router DOM

## Installation Process
 -npm install

## Start server:
 -npm run dev

## About Project
This project was built as a frontend practice project to strengthen React.js concepts such as component structure, state management, props handling, and UI design.
